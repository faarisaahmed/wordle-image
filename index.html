How Wordle colours tiles (and hard mode)
  1. Greens first. Every letter in the correct spot turns green, no matter where it sits in the word.
  2. Then yellows, left to right. The answer letters that weren't matched green form a pool. A guess letter is yellow only if the pool still has a copy of it, and that copy gets used up.
  3. Everything else is grey, including extra copies of a letter once the answer has run out of them.

So some pictures can't be made at all. If the answer is CRANE and a row is green, green, green, green, yellow, the only leftover letter is E, and an E in the last spot would be green. This page checks every row against these rules and tells you exactly which tiles are the problem.

Hard mode

This matches the check in the NYT game's own code, which only compares each guess with the one right before it:

  • Every green must stay in the same spot in the next guess.
  • Every green or yellow letter must appear in the next guess, at least as many times as it was coloured.
  • Grey letters can be reused, and a yellow letter can even go back in the same spot.

So in hard mode a green tile has to stay green in the row below, and a row can't have fewer coloured tiles than the row above it.
